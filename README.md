Welcome!

This is the repo for FikaBRos, an interactive public website that shows public bathrooms and Fika spots all around Stockholm, Sweden.
Current features include:
- a light map background and colored points indicating bathroom and Fika spots;
- filter option to see only bathrooms or only Fika spots;
- "Use my location" button to allow users to locate themselves on the map.

More features coming! Stay tuned...
